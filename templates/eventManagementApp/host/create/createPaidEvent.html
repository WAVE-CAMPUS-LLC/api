Crew Discounts

Encourage group attendance by offering automatic discounts when people purchase tickets as a crew (group). This feature helps boost attendance and creates a more vibrant event atmosphere.

  • Set minimum crew size to qualify for the discount
  • Define percentage discount applied to each ticket in the crew
  • Automatically calculated at checkout when minimum size is met
  • Great for events where group experiences enhance enjoyment
